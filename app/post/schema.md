# 게시글 관련 테이블 스키마 (Post Related Schema)

## 1. 게시글 테이블 (posts)

```sql
CREATE TABLE posts (
    post_id         NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    member_id       NUMBER NOT NULL,
    title           VARCHAR2(200) NOT NULL,
    content         CLOB NOT NULL,
    view_count      NUMBER DEFAULT 0 NOT NULL,
    like_count      NUMBER DEFAULT 0 NOT NULL,
    comment_count   NUMBER DEFAULT 0 NOT NULL,
    is_public       CHAR(1) DEFAULT 'Y' NOT NULL,
    is_temp         CHAR(1) DEFAULT 'N' NOT NULL,
    is_deleted      CHAR(1) DEFAULT 'N' NOT NULL,
    created_at      DATE DEFAULT SYSDATE NOT NULL,
    updated_at      DATE,
    deleted_at      DATE,

    CONSTRAINT fk_posts_member
        FOREIGN KEY (member_id) REFERENCES members(member_id),

    CONSTRAINT ck_posts_public CHECK (is_public IN ('Y', 'N')),
    CONSTRAINT ck_posts_temp CHECK (is_temp IN ('Y', 'N')),
    CONSTRAINT ck_posts_deleted CHECK (is_deleted IN ('Y', 'N'))
);
```

## 2. 태그 테이블 (tags)

```sql
CREATE TABLE tags (
    tag_id          NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name            VARCHAR2(50) NOT NULL,
    created_at      DATE DEFAULT SYSDATE NOT NULL,

    CONSTRAINT uk_tags_name UNIQUE (name)
);
```

## 3. 게시글-태그 연결 테이블 (post_tags)

```sql
CREATE TABLE post_tags (
    post_tag_id     NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    post_id         NUMBER NOT NULL,
    tag_id          NUMBER NOT NULL,

    CONSTRAINT fk_post_tags_post
        FOREIGN KEY (post_id) REFERENCES posts(post_id),

    CONSTRAINT fk_post_tags_tag
        FOREIGN KEY (tag_id) REFERENCES tags(tag_id),

    CONSTRAINT uk_post_tags UNIQUE (post_id, tag_id)
);
```

## 4. 좋아요 테이블 (post_likes)

```sql
CREATE TABLE post_likes (
    like_id         NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    post_id         NUMBER NOT NULL,
    member_id       NUMBER NOT NULL,
    created_at      DATE DEFAULT SYSDATE NOT NULL,

    CONSTRAINT fk_post_likes_post
        FOREIGN KEY (post_id) REFERENCES posts(post_id),

    CONSTRAINT fk_post_likes_member
        FOREIGN KEY (member_id) REFERENCES members(member_id),

    CONSTRAINT uk_post_likes UNIQUE (post_id, member_id)
);
```

## 5. 북마크 테이블 (bookmarks)

```sql
CREATE TABLE bookmarks (
    bookmark_id     NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    post_id         NUMBER NOT NULL,
    member_id       NUMBER NOT NULL,
    created_at      DATE DEFAULT SYSDATE NOT NULL,

    CONSTRAINT fk_bookmarks_post
        FOREIGN KEY (post_id) REFERENCES posts(post_id),

    CONSTRAINT fk_bookmarks_member
        FOREIGN KEY (member_id) REFERENCES members(member_id),

    CONSTRAINT uk_bookmarks UNIQUE (post_id, member_id)
);
```
